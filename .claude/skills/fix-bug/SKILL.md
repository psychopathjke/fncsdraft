# Починка бага

Он присылает баги пачками и ждёт починки, а не вопросов. Вопрос — только если скрин правда неоднозначен.

1. **Контекст.** Сначала журнал поломок (скил errlog) — там может быть точная строка и режим. Режим важен: короткий репорт «команды/таблица разошлась» почти всегда про онлайн («с другом»), а не одиночную карьеру.
2. **Найти место.** Grep по тексту интерфейса → ключ локализации (ru/en в I18N, index.html ~9890) → функция. Файл огромный: читать кусками по номерам строк, не целиком.
3. **Воспроизвести.** Проба в headless Chrome по образцу tools/check-*.js (см. скил new-guard). Для вида на телефоне — `node tools/check-iphone.js <папка>` (WebKit, iPhone 15 Pro Max) или Playwright на статическом сервере. Есть число «до» — есть доказательство.
4. **Причина, не симптом.** Особенно онлайн: расхождение двух клиентов — это ленивый кэш, личная память мира не в книге, асимметрия «свой/напарник», разная свежесть карточек. Чинить корень, комментарий в коде — по-русски, с датой и его цитатой/источником, как везде в файле.
5. **Правила проекта:** в интерфейсе нет длинных тире «—»; слово FIFA нигде; баланс — только по измеренным данным (не придумывать коэффициенты); его устройство — iPhone/Safari (reduced motion всегда включён).
6. **Правки index.html** — Edit (уникальный old_string). Не `node -e` с регулярками: Bash схлопывает обратные слэши. Скрипт правки — файлом через Write.
7. **Проверить:** проба «после», затем `bash tools/run-guards.sh` (или хотя бы затронутые сторожа). Красное на бейзлайне — сверить со старой сборкой (git worktree), прежде чем винить свою правку.
8. **Коммит** — хук сам проверит LF, размер диффа, FIFA. Сообщение: что и почему, с источником (Notion «ДД.ММ», X, Telegram, журнал).
9. **Не выкладывать на прод без его слова.** Debug — можно (скил deploy-debug).
10. Ответ: по-русски, по пункту на баг — что было, что сделано; не воспроизвелось — так и сказать, с тем, что проверено.
