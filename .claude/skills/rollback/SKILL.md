# Откат прода

Без его слова в разговоре — не откатывать (это прод).

1. Что на сайте и куда можно: `node tools/prod-rollback.js` — список папок прода, звёздочка у текущей.
2. Куда — по умолчанию на ПРЕДЫДУЩУЮ прод-папку (строка под звёздочкой); если он назвал дату — на неё.
3. Откат: `node tools/prod-rollback.js <ДД.ММбуква> --yes` — проверка папки (check-deploy-folder), wrangler на main, сверка app.js на fncsdraft.com и pages.dev.
4. Зеркало: `bash tools/push-mirror.sh "<папка>"` (команда печатается в конце).
5. Воркер (mp.fncsdraft.com) откатывать ОТДЕЛЬНО и только если ломался он: `cd server && npx wrangler deployments list`, затем `npx wrangler rollback <версия>`. Сайт старой сборки с новым воркером обычно работает (новые маршруты он просто не зовёт).
6. main и теги не трогать: откат — это выкладка старой папки, не переписывание истории. Чинить дальше — в main, новой выкладкой.
7. Ответ: на что откатили (дата, app.js), проверено на обоих адресах, ссылка отдельной строкой без точки, «Ctrl+F5, если видно старое». Строка в память fncsdraft-deploy-folder.md.
