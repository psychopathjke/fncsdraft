1. `notion-list-private-pages` (limit 5): верхняя — новейшая. `notion-fetch` по id. Если страница та же, что раньше в разговоре, — новые картинки в конце списка.
2. `notion-get-file-download-urls` по notion-file-block:// ссылкам; качать `curl -s -o N.png '<url>'` сразу (ссылка живёт 5 минут) в scratchpad/notion<ДДММ>/.

5. Для каждого: что не так → найти место (Grep по тексту интерфейса → ключ локализации → функция) → воспроизвести пробой (headless Chrome по образцу tools/check-*.js; для вида на телефоне — Playwright на http://127.0.0.1:8931 (scratchpad/srv.js), ширина 390) → править → проверить.
6. Если агент notion-triage доступен — можно отдать ему шаги 1–5 без правок, а править самому.
7. Правила: без длинных тире в интерфейсе, без слова FIFA, баланс только по данным, его телефон — iPhone/Safari. Меньше вопросов — больше правок; вопрос только если скрин правда неоднозначен.
8. Коммит (хук проверит правила), без выкладки на прод. Ответ по-русски: по каждому скрину одна-две строки, что было и что сделано; что не воспроизвелось — так и сказать.
9. Строка в память fncsdraft-notion-pages-index.md: дата, id страницы, что сделано.
