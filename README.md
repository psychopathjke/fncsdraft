# fncsdraft

Fan-made tournament simulator for Fortnite Competitive (FNCS) — draft a squad of real players who qualified for FNCS 2026, then run a full simulated tournament through Play-In, Heats, and Major Finals.

🔗 **Live site:** [fncsdraft.com](https://fncsdraft.com)

## Features
- Draft system with reroll mechanics and region filtering
- Probabilistic match simulation engine (weighted duels, kill streaks, squad-strength impact on outcome)
- Real player database — ~1,900 records pulled from 26 official FNCS tournaments (2022–2026), with sources per player
- Squad synergy system — bonuses for real teammates and shared nationality
- Achievement system and match history tracking
- Full RU/EN localization across the entire interface

## Built with
HTML, CSS, JavaScript — built AI-assisted (Claude), deployed on Netlify
