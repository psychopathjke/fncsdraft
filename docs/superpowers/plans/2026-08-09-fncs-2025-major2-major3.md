# FNCS 2025 Major 2 and Major 3 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship FNCS 2025 Major 2 (`t2`, event `S34_FNCSMajor2`) and Major 3 (`t3`, event `S36_FNCSMajor3`) as playable trio card modes, each on its own island with its own loot pool and its own counted bracket.

**Architecture:** Both sets ride the machinery Major 1 already built. `buildCardSetRegion(cfg)` is parameterised and is called seven more times per Major. What is currently hardcoded to `t1` — the raw row tables, the stage dates, the ledger, the map, the loot pool, the tile — becomes a lookup keyed `t1 | t2 | t3`. No new builder, no new simulation code, no change to any 2026 set.

**Tech Stack:** One `index.html` (~29 300 lines, vanilla JS, no build step). Node scripts in `tools/` generate literals that are pasted into it. Verification is headless Chrome driven from Node. Data is JSON in `~/Desktop/2025/`.

## Global Constraints

- **The working branch is `fncs-2025-trio-major`.** Do not create a new branch and do not merge to `main`.
- **Nothing on a card is invented.** Every number traces to Epic's payload, the Fortnite wiki, or a counted measurement. Where a value cannot be measured, it is left out and the gap is named in a code comment — never filled with a plausible guess.
- **Seasons never mix.** A `t2` card is rated on S34 alone; a `t3` card on S36 alone.
- **No 2026 card may move.** `m1` and `m2` ratings, rarities and OVRs are byte-identical before and after. This is gated by `tools/diff-card-ratings.js`, which exits non-zero on any drift.
- **The fourteen duo builders (`buildMajor1EU` … `buildMajor2OCE`) are not touched.**
- **Elimination points are 1 in the Last Chance Qualifier, 2 in the Play-In, 4 in the Grand Finals** — measured exact in all seven regions of both Majors. `T1_KILL` is shared by all three sets, not copied.
- **Theme:** all three 2025 sets use the existing `MODE_THEME.t1` entry. Epic's `imp_event.Colors` is identical across the three Majors' Grand Finals (`HighlightColor #FF0040`, `PrimaryColor #977EA5`, `BackgroundLeftColor #829FA9`, `BackgroundRightColor #FFFFFF`, `SecondaryColor #161616`). No new palette is authored.
- **Both languages, always.** Every user-visible string added to the `ru` block gets its counterpart in the `en` block in the same commit.
- **Commit style:** sentence-case imperative subject, a body explaining what was wrong or unknown and what the evidence says, and the `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>` trailer.
- Source data root: `~/Desktop/2025/` (`$SRC` below). Repo root: `~/Desktop/fncsdraftmajor/` (`$ROOT`).

```js
// Run in the console of an open fortnitetracker.com tab.
async function grab(url){
  const html = await (await fetch(url, {credentials:'include'})).text();
  const at = html.indexOf('var imp_leaderboard = ');
  if (at < 0) return null;
  let i = html.indexOf('{', at), d = 0, q = false, e = false, end = -1;
  for (let j = i; j < html.length; j++){
    const c = html[j];
    if (q){ if (e) e = false; else if (c === '\\') e = true; else if (c === '"') q = false; continue; }
    if (c === '"') q = true; else if (c === '{') d++;
    else if (c === '}'){ d--; if (!d){ end = j + 1; break; } }
  }
  return end < 0 ? null : JSON.parse(html.slice(i, end));
}
```

Convert each payload to the row shape with the same reducer the Major 1 harvest used: rank and `pointsEarned` from the entry, matches / wins / average eliminations / average placement from `sessionHistory`, `elimPoints` from `pointBreakdown["TEAM_ELIMS_STAT_INDEX:1"]`, and names from `internal_Accounts[id].esportsNickname || .nickname`.
