# Fortnite Manager «как в FIFA» — часть 3 (спека + план)

> Выбор владельца 7.10: «1234578» из списка «что ещё добавить». Исполнение — инлайн (superpowers:executing-plans), ветка `mgr-fc`, сторож `tools/check-mgr-hub.js`.

**Goal:** менеджер живёт годами и ощущается настоящей оргой: сезоны после 2026-го, криэйторы клуба, лента клуба, характер игроков, дедлайн трансферов, турниры академии, вызовы в сборные.

**Архитектура:** всё в `index.html` рядом с `mgr*`; новые поля `MGR.*`; тики — `mgrWeekly` (неделя), `mgrPayMonths` (месяц), `mgrAdvanceTo` (день), `mgrSeasonReview/mgrNextSeason` (год); экраны — подвкладки хаба. Числа эффектов — оценка режима (константы `MGR_*`).

## Global Constraints
- Подписи — `mgrT9()` ru/en; CSS менеджера — с `#screen-manager`.
- Детерминизм — `careerRng(ccHashStr(...))`.
- Данные людей — только настоящие (криэйторы из `CC_PROAM_CREATORS_*`, подписчики `CC_PROAM_TWITCH`, аватарки `ccProAmAvatar`); выдуманы только числа эффектов.

## Задачи

1. **Сезоны после 2026-го.** Итоги 2026-го больше не «последний год»: `mgrNextSeason` даёт 2027, 2028…; теневая карьера — 2026-й календарь со сдвигом сезона (`mgrShadow(year, region)` при year>2026 → year0 2026, `season = year−2025`, как `ccYearShift` карьеры). Данные — `mgrDataYear()=min(year, 2026)` везде, где читается год данных (`mgrClubsFor`, `mgrStartPoints`, работа в другом клубе). Старение: с 30 лет раз в месяц шанс −1 (0.2, с 33 — 0.35), уход из профи на стыке года с 33 лет (шанс 0.25, с 35 — 0.6) с письмом. Тест: итоги 2026 → 2027, хаб, турниры есть, год в шапке 2027; старение/уход на подложенном возрасте.
2. **Криэйторы клуба.** До 3 настоящих креаторов региона (Про-Ам списки + подписчики Twitch, аватарки). Контракт: ставка в месяц ∝ подписчикам; доход в месяц (спонсоры/мерч) ∝ подписчикам × репутация; репутация клуба +1/мес за каждого. Подвкладка Клуб → «Криэйторы». Тест: подписать, месяц → касса и репутация меняются по формуле, ставка в штабе.
3. **Лента клуба.** `MGR.feed` — посты: трансферы, итоги вечеров, награды, слухи (раз в неделю шанс: «клуб X интересуется твоим Y»), реакции (лайки ∝ репутации и событию). Вкладка «Входящие» → подвкладки «Почта / Лента». Тест: подписание/вечер/награда дают посты, слух появляется, лента рисуется.
4. **Характер игроков.** Детерминированно по нику: амбициозный, лояльный, звезда, профи, вспыльчивый, спокойный. Эффекты: продление (лояльный ×0.95, амбициозный ×1.15), мораль в запасе (звезда −1 быстрее), усталость (профи −1/нед), химия (вспыльчивый −1 с соседом), мораль после побед (амбициозный +1). Значок в листе и на карточке. Тест: распределение по ролям, эффекты на прибавке и химии.
5. **Дедлайн трансферов.** В последний день окна (`mgrWindows`) — «Дедлайн»: 2–3 предложения за твоих, 2–3 игрока «срочно доступны» со скидкой 30% к отступным; баннер на Центре; письма. Тест: шаг через конец окна даёт письма и баннер в этот день.
6. **Турниры академии.** Раз в месяц при ≥2 игроках академии — кап академий: место по силе + бросок, топ-3 → рост +1 у участника, письмо и пост. Тест: месяц с академией → результат, рост у топа.
7. **Вызовы в сборные.** В день Кубка наций сезона (или середина сезона, если его нет) — сильнейшие игроки клуба своих стран (топ-4 по стране в сцене) едут в сборную: усталость +8, шанс роста +1, письмо/пост. Тест: день вызова → вызванные, письмо, усталость.
8. Сезон целиком + debug.
