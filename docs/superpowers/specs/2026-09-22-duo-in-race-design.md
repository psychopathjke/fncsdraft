# Пара в гонке — два человека одной командой (22.09.2026)

**Откуда.** Письмо игрока 21.09 (п. 1): «дуо с другом скучно — только сим и тренировки, дайте split in duo / гонку на двоих». Владелец 22.09: «делай», вариант (а) — пара из двух людей одной командой в гонке против ботов и других пар.

**Что уже было.** Гонка карьер: N людей (до шести) в одной комнате, у каждого своя карьера и свои бот-напарники, вечер один на всех (общий сид, поле совпадает у всех, соперники сажаются по строкам `act 'race'`), вопросы дропа/лута адресные по `mpTag` (`ccMpMine`: отвечает тот, чей ник в адресе, остальные ждут ответ по проводу), барьеры на всех людей комнаты.

**Решение.** Пара — это две строки гонки, сидящие в одной команде. Ничего нового в локстепе:
- у каждого своя карьера (журнал, дивизион, рейтинг, деньги — своя половина через `ccShareOf`); общего состояния команды нет, общий только состав вечера;
- договор по проводу: `act 'pair' {by,to}` — приглашение, `'pairok'` — согласие, `'pairno'`, `'unpair'`; храним `cr.race.pair={id,nick,since}`; пара действует, пока строка напарника жива и несёт `pair === мой id`;
- состав вечера = две карточки людей в порядке по `hKey` (`ccRacePairCards`), сила — `careerTeam(cards, true)` без формы/химии/эфира (иначе у двоих разные числа), `mpTag` — по первой карточке; `ccRacePairTeamInto(you)` в `ccRaceFieldSync` переписывает `you` до строки с силой;
- строка гонки (`ccRaceMyLine`) везёт `mates=[карточка напарника-человека]`, `pair`, `bench=[свой бот]` — соперники вычитают bench из пула, как напарников (иначе поле разойдётся);
- соперники сажают чужую пару один раз — по строке старшего (первого по `hKey`), строка младшего не команда; свой напарник по паре в поле не садится (моя команда);
- вопросы пары решает старший (`ccMpMine` по адресу), младший ждёт, как ждёт ответы любого соперника;
- ограничения: один дивизион, один сезон, только дуо-сезон; вышел из гонки — `unpair`.

**Проверки.** `tools/check-race-pair.js` — живой воркер, две страницы: пара встала у обоих, в поле одна команда людей (`livea+liveb`), таблицы и броски совпали, вопросы шли к `livea`, места одинаковые. `tools/check-race-pair-offline.js` — договор, состав, адрес, строка, плитка без сокета.

**Не сделано / по слову.** Пара в трио-сезон (третий — чей бот?); химия пары (сейчас ноль — сила без химии); общая история пары в архиве.
