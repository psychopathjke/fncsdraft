# Карьера: год 2025 на выбор

Его слово, 20 сентября 2026: «сделай карьеру как для выбора с расписанием 2025
года полностью и игроки тоже из того года». Подтверждено: после 2025-го карьера
идёт в 2026-й (дуо, как было в жизни), дальше чередование как сейчас.

## Что уже есть

- `CAREER_YEAR_2025`, `CC_CUP_WEEKS_2025`, `CC_MAJOR_STAGE_2025`, `CC_CUP_2025`,
  `CC_YEAR_2025_FROM/TO` — измеренный календарь 2025 (19 августа), никем не читался.
- Карточки 2025: наборы t1/t2/t3 (семь регионов, трио, `CARD_TRIOS_BY_SET`),
  `GC2025_PRIZES` (Лион), региональные таблицы 2025.
- Трио-механика (третий, рынок трио, ЛАН втроём) — работает на календаре 2026.
- Мейджор 2026 уже содержит Last Chance Lobby (в тот же день, что LCQ).

## Решения

1. **Выбор года** на экране создания карьеры: 2026 (по умолчанию) / 2025.
   `cr.year` — календарный год, который играет ТЕКУЩИЙ сезон. Сейвы без поля = 2026.
2. **Календарь по году** — константы года заменяются функциями:
   `ccYearFrom() ccYearTo() ccYearRows() ccCupWeeks() ccEvalNights() ccNowYear()`.
   2025: PE нет (страниц на Tracker нет — не выдумываем), Reload/Summit/Pro-Am/GC LCQ нет.
   Кэш `careerYearDays` — по году.
3. **Сезоны Fortnite 2025**: S33 01.12.24–20.02.25, S34 21.02–01.05, S35 02.05–06.06,
   S36 07.06–06.08, S37 07.08–28.11. Сдвиг номера по годам карьеры считает только
   прожитые 2026-е годы.
4. **Формат**: 2025 — трио весь сезон (`cr.size=3`). На стыке 2025→2026 год
   становится 2026, размер 2; дальше чередование по чётности как сейчас, но с
   поправкой на то, что первый год был трио.
5. **Мейджор 2025** через ту же машину стадий:
   - `Major<n>_2025_PlayIn` → playin: 20 игр (2 дня × 10 одной сессией — упрощение), отсечка 99 → 33 трио.
   - `Major<n>_2025_Group1..3` → heats с `nth` = номер группы; групп всегда 3;
     5 игр, топ-5 + каждая победа; игрок играет ТОЛЬКО день своей группы.
   - `Major<n>_2025_LCQ` → lcq: 10 игр, отсечка 33, БЕЗ лобби в тот же день; пишет `pass:'lcq'`
     и сохраняет прошедших (`cr.majorLc`).
   - `Major<n>_2025_LCLobby` → новая стадия `lclobby`: комната из `cr.majorLc`, 3 игры, победа = билет.
   - `Major<n>_2025_Final` → final: 12 игр одной сессией (как 2026), призовые 2025.
6. **Игроки 2025**: в 2025-й год `ccNowYear()`=2025 — «текущие» карточки = 2025-е;
   `careerRosterEU` (сильнейшая карта) не берёт карты новее года;
   снимки сезона — t1 → t2 (с Плей-Ина Мейджора 2) → t3 (с Плей-Ина Мейджора 3);
   пул строится из трио-записей: пара = первые двое, третий пишется в `cr.trios` сразу.
   Острова трио-года переключаются по тем же датам Плей-Инов.
7. **Глобалы 2025** — Лион, 33 трио, `GC2025_PRIZES`; места региона — с финалов трёх Мейджоров
   (без Last Chance).

## Проверки

`tools/check-career-2025-calendar.js` (календарь, сезоны, размер, стык в 2026),
`tools/check-career-2025-major.js` (плей-ин → группа → LCQ → лобби → финал),
`tools/check-career-2025-players.js` (комната только из карт ≤ 2025, реальные трио t1).
